# `std::string_view`

`std::string_view` — небольшой объект, который ссылается на уже существующий непрерывный участок символов, не владея им. Его можно представить как пару: указатель на начало и длина.

```cpp
#include <string_view>

std::string_view view = "hello";
```

`view` не копирует строку и не выделяет для неё память. Поэтому копирование `string_view` обычно дёшево, а чтение через него не создаёт копии.

## Для чего он нужен

Частый случай — функция, которой нужно прочитать строку, но не изменять и не сохранять её:

```cpp
#include <iostream>
#include <string_view>

void print(std::string_view text) {
    std::cout << text << '\n';
}

int main() {
    std::string name = "Ada";
    print(name);    // std::string преобразуется в string_view
    print("Grace"); // можно передать строковый литерал
}
```

`string_view` позволяет передать и `std::string`, и строковый литерал без копирования содержимого. Он удобен и для разбора строки на части:

```cpp
std::string_view line = "ADD 125";

std::string_view command = line.substr(0, 3); // "ADD"
std::string_view argument = line.substr(4);   // "125"
```

`substr` возвращает ещё один вид на часть исходных символов; сама строка не копируется.

## Владение и время жизни

Главное правило: **символы, на которые смотрит `string_view`, должны оставаться живы, пока используется view**.

Безопасный случай:

```cpp
std::string text = "hello";
std::string_view view = text;

std::cout << view; // text ещё существует
```

Опасно возвращать view на локальную строку:

```cpp
std::string_view make_view() {
    std::string text = "hello";
    return text; // text уничтожится при выходе из функции
}
```

Полученный view ссылается на уже уничтоженную строку; чтение через него приводит к неопределённому поведению. Аналогично, нельзя сохранять view на временную строку:

```cpp
std::string_view view = std::string("hello");
// Временная строка скоро уничтожится — использовать view после этого нельзя.
```

Если функция должна хранить текст надолго, обычно ей нужно сохранить собственный `std::string`.

## Изменение исходной строки

Если изменить символы исходной строки, view увидит эти изменения. Но при перевыделении памяти старый указатель может стать недействительным:

```cpp
std::string text = "hello";
std::string_view view = text;

text[0] = 'H';
std::cout << view; // "Hello"

text += " world"; // строка может перевыделить память
// После этого view может быть недействителен.
```

Сам `string_view` не следит за изменениями источника.

## Это не C-строка

`string_view` хранит длину отдельно и не обязан заканчиваться нулевым символом. Например:

```cpp
std::string_view part = std::string_view("hello").substr(1, 3); // "ell"
```

`part.data()` указывает на участок, начинающийся с `"ello"`, а не на отдельную C-строку `"ell"` с завершающим нулём. Поэтому `data()` нельзя бездумно передавать функциям, ожидающим C-строку. При необходимости создай владеющую строку:

```cpp
std::string copy(part);
some_c_function(copy.c_str());
```

Для обычного вывода подходит поток:

```cpp
std::cout << part;
```

## Полезные операции

У `std::string_view` есть операции чтения, похожие на операции `std::string`:

```cpp
std::string_view s = "priority";

s.size();              // длина
s.empty();             // пустой ли
s[0];                  // символ по индексу
s.front();             // первый символ
s.back();              // последний символ
s.substr(0, 8);        // вид на подстроку
s.find("or");          // поиск
s.starts_with("pri");  // начало строки (C++20)
s.ends_with("ty");     // конец строки (C++20)
```

Индексация, `front()` и `back()` требуют корректного индекса или непустого view.

## Чего он не делает

`string_view` не владеет памятью, не освобождает её и не копирует строку. Он предоставляет только доступ для чтения символов.

`const std::string_view` запрещает переназначить сам view, но не управляет исходной строкой. И обычный, и `const` view дают доступ к символам только для чтения.

## Когда применять

Используй `std::string_view`, когда функция только читает строку в течение вызова:

```cpp
bool is_command(std::string_view text) {
    return text == "EXTRACT";
}
```

Используй `std::string`, если нужно владеть текстом, менять его или хранить после завершения текущей операции. Для коротких учебных программ `string_view` необязателен; это удобный инструмент, если важно избежать копирования и учитывать время жизни данных.
